# Compact, fast, recruiter-ready portfolio

## What will change
- Tighten vertical spacing, headings, card gaps, and footer height across every section without making the layout cramped.
- Reorder the main content so recruiters reach selected projects and core skills sooner; simplify repetitive learning and capability content.
- Replace the hero’s MERN / Next.js / REST counters with compact React, Next.js, Node.js, and MongoDB logo badges.
- Make certificate displays smaller and denser, with both credentials in a compact grid and less repeated text.
- Optimize the images actually shown on the page into high-quality WebP versions, size them to their display needs, preload the hero portrait, and lazy-load below-the-fold images.
- Improve search metadata for “Maruf Hasan portfolio” and related MERN developer searches, add the canonical URL, person/website structured data, and a sitemap referenced by crawler rules.

## Recruiter-focused structure
1. Hero: identity, role, availability, project/contact actions, and core stack badges.
2. Selected Projects: strongest evidence of work immediately after the hero.
3. About: concise profile, location, resume, and compact supporting skills.
4. Skills: scannable grouped expertise without subjective percentage ratings or repeated capability cards.
5. Journey: condensed progression rather than a long expandable timeline.
6. Certificates: compact proof of learning.
7. Contact: direct hiring and collaboration channels.

## Technical details
- Keep the existing dark/light design, animations, content facts, chatbot, links, and mobile resume behavior.
- Use bundled local assets only; preserve sharp source files while serving smaller high-quality renditions.
- Keep the single-page URL in the sitemap and omit generated `lastmod` dates.
- Validate desktop and mobile layout, all image loads, page height reduction, metadata, sitemap, and production build.
- Search ranking cannot be guaranteed; these changes establish strong on-page and crawl foundations. Current Semrush samples show no ranking data yet, so that is treated as unknown rather than zero visibility.
